# Task Management App

## UI (React)
- Location: `UI/react-todo-app`
- Configure the `.env` file as needed.
- Install dependencies:
  ```bash
  npm install
  ```
- Run the development server:
  ```bash
  npm run dev
  ```

## Backend (.NET Core)
- Location: `TaskManagementApp/src/Todo.WebAPI`
- Restore dependencies:
  ```bash
  dotnet restore
  ```
- Build the project:
  ```bash
  dotnet build
  ```
- Run the API:
  ```bash
  dotnet run
  ```
